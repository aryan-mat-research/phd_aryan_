# Aryan — Research Portfolio

A minimal, black-and-white, multi-page academic research website inspired by the editorial layout of your FolioPage site. Built with HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About and research interests
- `research.html` — Searchable/filterable project directory
- `experience.html` — Research and education timeline
- `notebook.html` — Research notes template and methodology
- `contact.html` — Email and LinkedIn

## Preview locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser.
3. Use the top navigation to move between pages.

No build tools are required. Google Fonts are optional; if offline, the site falls back to Georgia and Arial.

## Update content
- Edit the text directly in the relevant HTML page using VS Code or another text editor.
- Shared design is in `assets/css/style.css`.
- Mobile navigation and research search/filter behavior are in `assets/js/site.js`.
- Put approved research images in `assets/images/`. Add image tags with meaningful `alt` text when ready.
- Put approved reports in `files/projects/`, presentations in `files/presentations/`, and your final CV PDF in `files/cv/`. Then add a link to the exact filename in the appropriate HTML page.
- No CV, publications, results, or downloadable research files are fabricated or linked.

## Publish
Upload the extracted folder to a static hosting provider such as GitHub Pages. Keep relative file paths intact. For GitHub Pages, create a repository, upload the folder contents to the publishing branch/root, and enable Pages in repository settings.

## Verify before public release
- Confirm IIT Hyderabad title and appointment dates.
- Verify roles/dates for earlier research experiences.
- Review project descriptions and exact contributions.
- Add only approved figures and documents; do not publish confidential lab or collaborator material.
- Add a real CV and optional professional profile links when available.
- Test the published site on phone and desktop.

## Design notes
The palette is strictly black, white, and neutral greys for borders and secondary text. The structure follows a quiet editorial portfolio: wordmark and top navigation, small uppercase section labels, serif headlines, thin rules, and compact factual metadata.
