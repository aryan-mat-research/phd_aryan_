ARYAN RESEARCH WEBSITE PACKAGE

FILES
- research.html: research archive page with search/filter and links to detailed project pages.
- projects/*.html: one detailed page for each project card.
- assets/css/research.css: styles extracted from the research archive.
- assets/css/project-detail.css: styles for project detail pages.
- assets/js/research.js: search, filter, and image-loader script extracted from the archive.
- assets/css/style.css and assets/js/site.js are shared site files referenced by the original page but were not included in the uploaded text. Keep your existing copies in these locations.

HOW TO USE
1. Copy research.html into your website root.
2. Copy the projects folder into the same root.
3. Copy research.css and project-detail.css into assets/css/.
4. Copy research.js into assets/js/.
5. Keep your existing assets/css/style.css, assets/js/site.js, index.html, about.html, experience.html, notebook.html, and contact.html.
6. Add images under assets/images/projects/ and update each relevant figure's data-image path in research.html. For detail pages, replace the figure placeholder with a real image path.
7. Open a project page and replace bracketed guidance/example rows with verified results, data file paths, and real references. Delete any example row or reference you do not replace.

IMPORTANT
- No unsupported scientific results or literature citations have been invented. Detail pages contain structured prompts and placeholders where project-specific evidence must be inserted.
- The existing shared stylesheet/site script were referenced by the original page but were not part of the supplied HTML, so they are not overwritten here.
