Deterministic and Stochastic Modeling of Adsorption

A compact computational study comparing a mean-field kinetic model with stochastic Gillespie simulations to describe Pb²⁺ adsorption on Fe₃O₄@ZnO using time-dependent experimental uptake data.

01 / EXPERIMENTAL DATA

Adsorption kinetics

The model was developed using the six reported contact-time measurements for Pb²⁺ uptake by Fe₃O₄@ZnO. The experimental batch contained 40 mg adsorbent in 50 mL solution, with a reported starting concentration of 279.93 ppm.

02 / MODELING APPROACH

Deterministic and stochastic models

A mean-field ordinary differential equation was first fitted to the measured uptake profile. Its fitted rate constants were then used in a Gillespie stochastic simulation algorithm to generate independent adsorption and desorption trajectories.

01 / DETERMINISTIC

Mean-field ODE

Fractional site occupancy was evolved using adsorption and desorption rates, with the solution concentration updated through a finite-reservoir mass balance. Parameters were estimated by bounded nonlinear least squares.

02 / STOCHASTIC

Gillespie KMC

Adsorption and desorption events were sampled using the Gillespie stochastic simulation algorithm on a coarse-grained lattice. The ensemble contained 200 independent trajectories.

\( \displaystyle \frac{d\theta}{dt}=k_{\mathrm{ads}}C(1-\theta)-k_{\mathrm{des}}\theta \)

The stochastic model used 300 simulated sites. This site count is a coarse-graining assumption, not a measured number of physical adsorption sites.

RESEARCH ROLE

My contribution

Computational implementation, parameter estimation and analysis of the adsorption-kinetics model.

  1. 01Organised the experimental Pb²⁺ adsorption-kinetics data and checked uptake values using the batch mass balance.
  2. 02Implemented and fitted a finite-reservoir mean-field ODE model using nonlinear least squares.
  3. 03Developed a Gillespie stochastic simulation to model adsorption and desorption events across a coarse-grained site lattice.
  4. 04Compared the stochastic ensemble response with the deterministic fit and experimental measurements.
